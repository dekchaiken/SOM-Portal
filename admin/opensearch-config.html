Config for the SM log viewer (service-performance.html → View Logs)
Each endpoint = 1 OpenSearch cluster the log viewer can query (basic-auth user/pass). Default index pattern is what auto-loads when the viewer opens (e.g. logstash-tmn-*-applog-*). Extra patterns are picker options. Dashboards URL is optional — used only to build the "Open in OpenSearch" deeplink. Passwords are stored in data/sm/opensearch_config.json (SM-only file).
