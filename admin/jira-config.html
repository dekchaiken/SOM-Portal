จัดการ Service Types · Categories · Issue Types · Custom Fields ที่ใช้ใน Jira Templates

Service Types & Sub Types ต้นไม้ซ้ายมือใน Jira Templates

จัดหมวดหมู่ template เช่น Service Bank มีลูก GSB / KBANK / KTB
SM Lead และ Admin เพิ่ม แก้ชื่อ ลบได้

Template Categories ไม่ส่งไป Jira — ใช้จัดหมวดใน app

ตัวเลือก dropdown Category ตอนสร้าง template เช่น Incident, Change, Problem, Request
ใช้จัดกลุ่มภายใน — ไม่ถูกส่งไป Jira โดยตรง

Issue Types ส่งไป Jira จริง — issuetype field

ตัวเลือก Issue Type ตอนสร้าง template ค่านี้จะถูกส่งไป Jira API ตรงๆ
ต้องตรงกับ issue type จริงๆ ใน Jira project SMC เช่น Task, Bug, Story, Epic

Custom Fields fields ที่แสดงใน form New Template

กำหนดได้ว่า form New Template จะมี field อะไรบ้าง เปิด/ปิด หรือเพิ่ม field ใหม่จาก Jira
หา field ID ได้จาก Jira Console: เปิด Jira → F12 → Console → รัน: fetch('/rest/api/3/field').then(r=>r.json()).then(fields=>{const c=fields.filter(f=>f.custom);console.log(JSON.stringify(c.map(f=>({id:f.id,name:f.name})),null,2))})
