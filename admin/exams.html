Tier 1 — Foundation

รากฐานความเป็นธรรม — ลดโอกาสลอกด้วยการสุ่มและจำกัดเวลา/จำนวนครั้ง
Question Pool — สุ่มจากคลังข้อสอบ
มีข้อสอบในคลัง N ข้อ แต่สุ่มแสดงให้ผู้สอบแค่บางข้อ คนละข้อกัน
Shuffle Questions — สลับลำดับข้อ
ลำดับข้อต่างกันต่อคน ทำให้คนนั่งข้างกันไม่เจอข้อเดียวกันพร้อมกัน
Shuffle Choices — สลับลำดับตัวเลือก
ตัวเลือก A B C D สลับตำแหน่งต่อคน (ไม่กระทบ True/False และ Short Answer)
Attempt Limit — จำกัดจำนวนครั้ง
กำหนดได้ว่าทำได้กี่ครั้ง และต้องเว้นเวลาเท่าไหร่ก่อนทำใหม่
Time Limit — จำกัดเวลา
หมดเวลาแล้วระบบจะส่งข้อสอบให้อัตโนมัติ บีบให้ไม่มีเวลาแชร์คำตอบ

Policy & Consent — ข้อตกลงก่อนเริ่มสอบ

แสดงนโยบาย/ข้อชี้แจงก่อนผู้สอบเริ่มทำ เช่น "ใช้คะแนนเป็นเกณฑ์ประเมิน" — เปิดหรือไม่ก็ได้
เปิดใช้ Policy / คำยินยอม
ผู้สอบจะเห็นกล่องนโยบายม่วงระหว่างกติกาและปุ่ม "เริ่มสอบ" ถ้าตั้งบังคับติ๊ก ปุ่มจะ disable จนกว่าจะติ๊ก
ใช้ <p>, <ul>, <li>, <b>, <h4>, <strong> ได้ตามปกติ

Tier 2 — Deterrents

ตัวยับยั้ง — ทำให้การลอกหรือส่งต่อข้อสอบทำได้ยากขึ้น
One Question At A Time — แสดงทีละข้อ
ผู้สอบเห็นทีละข้อ ทำให้ถ่ายรูปรวบรวมข้อยาก / ส่งต่อข้อสอบทำได้ยาก
Tab Switch Detection — ตรวจการสลับแท็บ
ตรวจจับว่าผู้สอบสลับไปแท็บอื่น/หน้าต่างอื่นกี่ครั้ง — นับสะสมตลอด attempt (ไม่รีเซ็ตรายข้อ)
0 = ไม่จำกัด (แค่บันทึก log) · ตัวอย่าง: 3 = สลับได้ 3 ครั้ง ครั้งที่ 4 จะเข้าสู่ action ด้านขวา
ตัวอย่าง: 10 = คะแนนสุดท้ายจะโดนหัก 10% เมื่อผู้สอบสลับเกินโควตา
0 = ปิด · ค่าแนะนำ 3 = ในข้อเดียวสลับได้ 3 ครั้ง ครั้งที่ 4 ระบบล็อกข้อนั้น ทำต่อไม่ได้และกลับมาแก้ไม่ได้ (ต้องใช้ร่วมกับ One-at-a-time ถึงจะได้ผล)
Watermark — ลายน้ำชื่อผู้สอบบนหน้าจอ
ทับชื่อผู้สอบแบบโปร่งใสบนหน้าจอ ถ่ายรูปแชร์จะติดชื่อไปด้วย
Exam Window — ช่วงเวลาที่เปิดให้สอบ
เปิดให้เข้าสอบเฉพาะช่วงเวลาที่กำหนด ทุกคนเริ่มพร้อมกัน → คุยกันแทบไม่ทัน
Lazy Fetch — โหลดข้อสอบทีละข้อ
ไม่โหลดข้อสอบทั้งชุดมาที่ client ตั้งแต่แรก — กด "ข้อถัดไป" ค่อยขอจาก server
Course Prerequisites — ต้องผ่านคอร์สเรียนก่อน
เลือกคอร์สที่ผู้สอบ ต้องเรียนจบทุก phase ก่อนจึงจะเปิดให้ทำข้อสอบนี้ได้ (ไม่เลือก = ไม่ล็อก) — ดึงจากระบบ Learning

Tier 3 — Strict

ระดับเข้ม — สำหรับการสอบที่ต้องการความเข้มงวดสูง อาจกดดันผู้สอบ
Fullscreen Lock — บังคับ fullscreen
บังคับให้ทำข้อสอบในโหมด fullscreen หลุดออกจะถูกบันทึก
Disable Copy / Paste / Right-click
ป้องกันการคัดลอกข้อสอบ (กันได้แค่ระดับนึง คนเก่งจริงเลี่ยงได้ แต่เป็น deterrent)
Anomaly Detection — ตรวจจับพฤติกรรมผิดปกติ
flag คนทำเร็วผิดปกติ หรือสองคนตอบเหมือนกันเป๊ะ ให้แอดมินรีวิว
