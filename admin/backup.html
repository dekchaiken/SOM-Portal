ยังไม่มี Backup
กดปุ่ม + สร้าง Backup ตอนนี้ เพื่อสำรองข้อมูลครั้งแรก
หรือรอ Auto-Backup ที่จะทำงานอัตโนมัติทุก 7 วัน
วิธี Restore จาก Backup
ถ้าเว็บมีปัญหา ทำตามขั้นตอนนี้
  1. ดาวน์โหลด backup .zip ล่าสุดจากหน้านี้ไว้ที่เครื่อง
  2. Clone หรือ deploy โปรเจ็กต์ใหม่บน server
  3. แตกไฟล์ .zip แล้ว copy ทุกไฟล์ไปวางใน data/ ทับไฟล์เดิม
  4. ระบบจะกลับมาทำงานปกติโดยไม่ต้อง config ใหม่
แนะนำให้ดาวน์โหลด backup เก็บไว้บนเครื่องหรือ Google Drive เป็นประจำเพิ่มเติมด้วย
