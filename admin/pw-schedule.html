Google Chat Webhook
URL ที่จะใช้ส่งสรุป PW ไปยังห้อง chat
ผู้ใช้ทั่วไปมองไม่เห็น URL นี้ — เก็บเฉพาะสถานะ “ตั้งค่าแล้ว / ยังไม่ตั้ง”
ส่งการ์ดทดสอบไปยังห้องที่ URL ชี้ไว้ (ไม่ทำลาย webhook log)
↻
Google Sheet Sync (n8n)
ปุ่ม “Sync Sheet” ในหน้า PW จะเรียก n8n webhook นี้
workflow ของ n8n ต้องตอบกลับเป็น JSON shape { items: [...] } — ดูตัวอย่างใน n8n-workflows/pw-schedule-sync.json
▦
Teamup Calendar Sync
ตารางเดือนในหน้า PW จะดึงงานจาก Teamup calendar นี้ (cache 5 นาที)
ใส่ได้ทั้ง key ล้วน หรือ URL แชร์ — ระบบจะดึงเฉพาะ key ออกมาให้
Share endpoint = XHR ที่ browser ยิงเวลาเปิดหน้า teamup.com/{key} — ได้ข้อมูลครบเท่า API (subcalendar_id, notes, who, custom). ข้อเสียคือ undocumented → ถ้า Teamup เปลี่ยนอาจต้องสลับไปใช้อีก mode
กดเพื่อลอง fetch events ของเดือนปัจจุบันจาก Teamup (จะบันทึกก่อนถ้ามีการเปลี่ยน)

ค่าพื้นฐาน 10, 5 นาที — ใส่ได้หลายค่า, แต่ละค่าจะยิง noti + เสียงหนึ่งครั้ง
