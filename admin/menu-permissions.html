Menu Permissions

กำหนดสิทธิ์การเข้าถึง sidebar menu แยกตาม role — ปิดเมนู default จะเห็นทันทีที่ user login ใหม่

มีการเปลี่ยนแปลงที่ยังไม่บันทึก

Role × Menu matrix

คลิก checkbox เพื่อ toggle การเข้าถึง · คลิกชื่อ role ที่ header เพื่อ wildcard (ทุกเมนู) · ปุ่ม ALL/NONE ใน bulk row = toggle ทั้ง column
ⓘ External role: matrix นี้เป็น default template — เวลาสร้าง external user ใน Users page เลือก permission ต่อคนได้ ซึ่งจะ override matrix นี้เสมอ

Preview — สิ่งที่แต่ละ role เห็นในปัจจุบัน

รายการนี้จะ update ทุกครั้งที่ toggle matrix (ยังไม่ save)
