A — Pinned Section
Hover บน nav item จะเห็น icon 📌 pin โผล่ขวาสุด กดปุ๊บ item นั้นขึ้นไปอยู่ใน section PINNED ด้านบนสุดของ sidebar แยกออกจาก MAIN ชัดเจน
  • เก็บ pinned IDs ใน localStorage (key: som_sb_pins) → per-user, per-browser
  • Section PINNED ซ่อนตัวเองอัตโนมัติถ้าไม่มีอะไร pin
  • Pin icon ใช้ Lucide "pin" ที่มีใน Icons library อยู่แล้ว
  • Item ใน PINNED section ยังคงแสดงใน MAIN ด้วย (duplicate = navigate ได้จาก 2 ที่)

B — Quick Access Bar
แถวไอคอนขนาดเล็กใต้โลโก้ กด ★ บน item เพื่อ add/remove จาก quick bar โดย sidebar หลักไม่เปลี่ยนรูป เพียงแต่ item ที่ starred จะมีดาวเล็กๆ ค้างไว้
  • Quick bar = icon-only, max 6 items, มี tooltip hover
  • + ปุ่ม add shortcut → เปิด mini picker หรือ drag & drop
  • Sidebar ปกติเหมือนเดิม 100% ไม่มี section ใหม่
  • Keyboard shortcut: Alt+1..6 → navigate ไป quick item

C — Stars & Favorites
กด ★ บน item → item ลอยขึ้น section "⭐ FAVORITES" ด้านบนโดยอัตโนมัติ ไม่ duplicate (item หายจาก MAIN แล้วไปอยู่ FAVORITES แทน) แนวเดียวกับ Notion sidebar
  • Section FAVORITES = ข้ามไปยัง page เดิม ไม่ใช่ copy
  • Hover บน favored item → ★ สีทอง ใน FAVORITES section
  • กด ★ อีกครั้ง → item กลับลง MAIN ในตำแหน่งเดิม
  • Favorites drag-to-reorder ได้ใน section FAVORITES

D — Edit Mode Drawer
"Customize" ใน sidebar footer → เปิด drawer ด้านขวา แสดง items ทั้งหมดพร้อม: drag handle เพื่อ reorder, pin toggle, eye toggle เพื่อ show/hide sidebar ปกติ clean ที่สุด ไม่มี UI extra
  • Hidden items หายออกจาก sidebar ปกติ (แค่ user นั้นคนเดียว)
  • Reorder แบบ drag ทำได้ทั้ง section
  • Pin items ขึ้น PINNED section ด้านบน
  • Reset button คืนค่าเป็น default

E — Dual-zone Sidebar
Sidebar แบ่งเป็น 2 zone: แถบซ้ายแคบ (36px) = icon-only favorites ตลอดเวลา + แถบขวา = full nav ปกติ กด ★ บน item → ปรากฏใน left strip ทันที แนวเดียวกับ Slack
  • Left strip ไม่หายไปแม้ sidebar จะ collapse
  • Hover icon ใน strip → tooltip แสดงชื่อ
  • Full nav ด้านขวาแสดง FAVORITES section + ALL items
  • Sidebar collapsed → แสดงแค่ left strip (favorites ยังกด ได้)
