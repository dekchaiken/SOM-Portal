n8n Push Config

n8n จะดึง monitor list และส่งผลการเช็คมาที่ endpoint นี้
นำ Push URL และ Push Key ไปวางใน n8n workflow

n8n workflow ควรทำ:
1. Schedule Trigger ทุก 1 นาที
2. GET Push URL พร้อม header X-Uptime-Key → ได้ monitor list
3. เช็ค URL แต่ละตัว (HEAD request)
4. POST ผลลัพธ์กลับมาที่ Push URL
5. ถ้า state เปลี่ยน → ยิง Google Chat
