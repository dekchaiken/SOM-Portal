Public Base URL ตั้งค่านี้เพื่อซ่อน sm-logo.gif chip ใน Gmail inbox
ทำไมต้องตั้ง URL นี้?
Gmail มี "attachment chip" ในหน้าอินบ็อกซ์ที่แสดง inline images ทุกอันเป็นไฟล์แนบ — ซ่อนไม่ได้ผ่าน MIME header ใดๆ

ตั้งค่า URL: ระบบจะโหลด GIF ผ่าน <img src="URL/uploads/sm-logo-typewriter.gif"> แทน CID → ไม่มี chip
ไม่ตั้ง: ระบบจะฝัง GIF แบบ CID attachment → ยังมี chip sm-logo.gif ในหน้าอินบ็อกซ์

ข้อกำหนด: URL ต้องเป็น public (เข้าถึงได้จาก Gmail server) เช่น https://your-domain.com — localhost จะไม่ทำงาน
