A Full-Split Immersive — ดราม่า, เลือกแล้วรู้สึกชัด, ทำให้รู้สึก "กำลังเลือก path"

สองฝั่งแบ่งเท่ากัน — ซ้ายคอร์ส (ส้ม), ขวาข้อสอบ (น้ำเงิน). เห็น stats + progress ทันที. Hover แล้วกดเข้าไปได้เลย. เหมาะถ้า user ยังไม่รู้ว่าจะทำอะไรก่อน.

B Centered Decision Hub — สะอาด, minimal, focus ที่ตัวเลือก

C Pill Tab + Content Below — familiar, low-friction, power-user friendly

Hero แสดง overview สถิติ. แล้วมี pill tab เลือก mode. content slide มาข้างล่าง. เหมาะกับ user ที่ switch ไปมาบ่อย หรืออยากดู all-in-one. ข้างล่างจะแสดง คอร์ส/สอบ แบ่งเป็น "จบแล้ว" กับ "ยังไม่ได้เรียน" ชัดเจน.

วิธีอ่าน mockup นี้:
A — ดีที่สุดถ้าต้องการให้ user รู้สึกว่า "เลือก path" อย่างชัดเจน · เห็น 2 mode ก็รู้ทันที

C — Power-user friendly · switch mode ง่าย · เห็น list แบบแยก "จบแล้ว / ยังไม่ได้" ชัดเจนที่สุด
D — Info-dense · ดูเยอะสุด · เหมาะถ้าอยากได้ dashboard รวมทุกอย่างไว้ที่เดียว
