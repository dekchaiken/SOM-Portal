# SOM Portal: v1 กับ v2 เทียบกันตอนนี้ (ตรวจ 2026-10-13)

เอกสารนี้ตรวจระบบ v1 (PHP, `/home/user/SOM-Portal`) และ v2 (Next.js, `som-portal-v2`) ใหม่ทั้งหมด เป็นสถานะล่าสุดหลังมี Learn รอบ 1–3, Mail และ team mailbox แล้ว ใช้แทน snapshot เดิมใน `PAGE-INVENTORY.md`

## วิธีตรวจ

- ตั้งใจใช้ skill `wayfinder` แต่ในเซสชันนี้ไม่มี skill ชื่อนี้ จึงตรวจด้วยวิธีอื่น: ไล่หน้า v1 ทั้ง 136 หน้า (top-level `*.html` และ `admin/*.html` ที่ใช้งานอยู่) เทียบกับ route จริงของ v2 (`app/**/page.tsx` มี 42 หน้า) แล้วปรับสถานะด้วยการตรวจเอกสาร `COMPARE-PHASE2.md` และ `AUDIT-V1-VS-V2.md`
- นิยามสถานะ: **PRESENT** = มี route และทำงานหลักได้ · **PARTIAL** = มี route แต่ยังขาด feature ที่ v1 มี · **MISSING** = ยังไม่มี route
- วิธีนับ %: `(PRESENT + 0.5 × PARTIAL) ÷ จำนวนหน้า` เป็นตัวเลขหยาบ เพราะหน้าใหญ่กับหน้าเล็กนับเท่ากัน ตัวเลขนี้บอกภาพรวมได้ แต่ไม่ได้บอกความสมบูรณ์ของฟีเจอร์

- File to Job Lookup, Batch Monitor (อ่านอย่างเดียว), Jenkins build, Jenkins Servers admin
- Mail: ส่งพร้อม CC, mail logs (บันทึกทุกการส่งแล้ว), templates, Global CC, signature, แยกเมลตามทีม (super_admin ตั้งให้ทีมอื่นได้)

## ความเสี่ยงและหนี้ทางเทคนิคที่รู้แล้ว

- **Mail team mailbox:** app password ยังเก็บเป็น plain text เหมือน v1 รอการตัดสินใจเรื่องการเข้ารหัส (ดู PR #10 และข้อความสรุป)
- **Inbox** ยังไม่มี ต้องเพิ่มไลบรารี `imapflow` (ตรวจแล้วติดตั้งได้จาก npm)
- **Exam anti-cheat** ฝั่ง client อย่างเดียว (fullscreen, copy/paste) ฝั่ง server บันทึก event และ penalty ได้ แต่บล็อกไม่ได้
- **Blur** ถูกบันทึกแต่ไม่หัก (defect 5, รอการตัดสินใจ)
- **CSRF** ยังไม่มีบน POST route ทั้ง v2
- **Type errors:** tsc มี error เดิมประมาณ 163 ตัว ไม่ได้เพิ่มจากงานล่าสุด (ตรวจเทียบ baseline แล้ว)
- **Unit tests:** vitest ล้มอยู่ 4 ตัวจากเดิม (`src/ma`, `src/opensearch`, `src/service-performance`)
- **ข้อมูล v1 บางแถวอ่านไม่ได้ตาม schema v2** (เช่น attempts 5 จาก 121) ระบบจะเก็บแถวเหล่านี้ไว้เมื่อเขียนไฟล์ ไม่ลบ
- **Emoji ในข้อมูล v1** (ชื่อและไอคอนของข้อสอบ) แสดงตามที่เก็บไว้

## แผนแบ่งงาน (เสนอ ให้แต่ละคนรับเป็นส่วน)

1. **Learn admin (รอบ 4):** สร้าง/แก้คอร์ส phase บทเรียน quiz ข้อสอบ question pool พร้อม validation และ owner guard
2. **Learn รายงาน (รอบ 5):** รายงานความคืบหน้า รายงานข้อสอบ และการแจ้งเตือน Google Chat
3. **Mail ต่อ:** inbox (imapflow), reply, dashboard widget, branding header/footer, และการเข้ารหัส app password
4. **Phase 2 ที่เหลือ:** MA Services, MA Status (admin และ cache writer), Restart Monitor (รายงานรายเดือน), Restart Analyzer (ขั้น 4–7, 9, 10), Service Performance (กราฟ alert compare), Log Explorer (ช่วงวันที่เอง export CSV), Incident Launcher (9 ขั้น war room), Scheduled notifications (exclude dates, test send, `grafana_paused`, `shift_summary`)
5. **Phase 1 ที่เหลือ:** dashboard ครบ 11 แหล่ง, board แก้ไข/อัปโหลด, Jira create-issue, admin reset password และ welcome email
6. **Phase 3 (หน้าอื่น 85 หน้า):** แบ่งตามกลุ่มเมนูของ v1 เช่น Home (about, dev hub, my team, onboarding, schedule, sheets), Monitor (alert monitor, grafana alerts, monitoring), Admin (announcements, leave approval, super admin, dev tools)
7. **งานข้ามระบบ:** CSRF, ทำ Playwright test ให้ Phase 2 (ตอนนี้ยังไม่มี), ทำให้ tsc และ vitest ที่ล้มอยู่สะอาด

## ข้อสรุปสั้นๆ

- ระบบแกนหลัก (login, สิทธิ์ทีม, scheduler, UI, board) ใช้งานได้ และ Learn รอบ 1–3 เสร็จแล้ว
- v2 ยังไม่ครบ v1: ประมาณ 24% ของหน้า และ Phase 3 ยังเริ่มน้อยมาก
- ลำดับที่แนะนำ: ปิด Mail (inbox และเข้ารหัส) ก่อน เพราะเป็นของที่ผู้ใช้ขอเจาะจงแล้ว จากนั้น Phase 2 แล้วค่อย Phase 3
