Import MA Services from CSV

Copy ข้อมูลจาก Excel/CSV แล้ว Paste ลงในช่องด้านล่าง

วิธีใช้งาน
1. เปิดไฟล์ Excel/CSV ของคุณ
2. เลือกข้อมูลทั้งหมด (รวม header) แล้ว Copy (Ctrl+C)
3. Paste ลงในช่องด้านล่าง (Ctrl+V)
4. กดปุ่ม "Import Data"

Format ที่รองรับ:
Columns: MA Service Name, Service, Tool, เปลื่ยนข้อความ ได้ หรือ ไม่, Link-Manual, Remark
MA Service Name Service Tool เปลื่ยนข้อความ ได้ หรือ ไม่ Link-Manual Remark Login TrueMoney Wallet TMN Jenkins YES Link แบบ MAS + Redis ใช้งานได้
