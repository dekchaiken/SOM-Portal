Solution

SOM-Portal.
One Hub สำหรับทุกอย่าง

ระบบ Central Hub ของทีม SM รวมทุกเครื่องมือไว้ในที่เดียว ลดการสลับแท็บ ลด human error และเป็น single source of truth สำหรับทีม Service Operations

  • รวมทุกเครื่องมือ — Board · Jira · Jenkins · Grafana · OpenSearch
  • Multi-team — SM · Dev team ใช้ร่วมกัน ข้อมูลแยกกันสมบูรณ์
  • RBAC 3 ระดับ — sm_user · sm_lead · sm_admin
  • Security-first — JWT HS256 · bcrypt · rate limit · audit log
  • No DB required — JSON file-based ดูแล deploy ง่ายมาก

Architecture

เรียบง่าย.
แต่ครบ

  • No Framework — PHP procedural อ่านง่าย debug ง่าย ไม่มี dependency หนัก
  • File-based Storage — JSON + flock() ไม่ต้อง setup DB · backup คือ zip เดียว
  • Zero Build Step — Clone → set .env → php -S · ใช้ได้ทันที
  • JWT + bcrypt — HS256 signed token · password_hash() · rate limit 120 req/60s
  • Multi-team Isolation — teamDataPath() แยก data/sm/ data/dev/ ไม่รั่วข้ามทีม
  • Host Cooldown — Circuit breaker ป้องกัน hammer upstream ที่ล่ม

Feature 04

Multi-team
Architecture

  • JWT team claim — ทุก request resolve data path ตาม team อัตโนมัติ
