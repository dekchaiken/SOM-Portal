SOM-Portal — Setup Guide

Run this web app on MAMP (or any PHP server)

1. Prerequisites

  • MAMP installed and running (Apache + PHP 7.4+)
  • PHP extensions required: curl, json, fileinfo (all on by default in MAMP)

2. Install

  1. Copy the centralize-som/ folder into MAMP's htdocs/
  2. Ensure the folder path is: htdocs/centralize-som/
  3. Make sure MAMP Apache is running on port 8888 (default) or 80

3. File Permissions

Give write permission to these folders (PHP needs to write JSON files):

chmod 755 centralize-som/data/
chmod 755 centralize-som/uploads/board/

On Windows (MAMP), these permissions are usually automatic.

4. Open in Browser

Navigate to: http://localhost:8888/centralize-som/

5. Default Admin Login

Username: admin

Password: Admin@SM2024!

You will be forced to change this password on first login.

6. Create Team Users

  1. Login as admin → go to Admin Panel → User Management
  2. Click Create User
  3. Fill in Name, Username, Role
  4. A temporary password (SOM_XXXXXX) is generated automatically
  5. Share the temp password — user must change it on first login

7. Jira Integration

Already configured in api/config.php:

Jira URL: https://truemoney.atlassian.net

Project: SMC

Email + API Token: pre-configured

To update token, edit api/config.php → JIRA_TOKEN

8. Add More Data Later

All data is stored in data/*.json — you can edit these directly or manage via the Admin Panel.

9. Security Note

The data/ folder is protected by .htaccess (deny all direct access). Only PHP can read/write the JSON files. JWT tokens expire after 8 hours.
